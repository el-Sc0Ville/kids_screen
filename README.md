# Twrlzy

(Started life as "Popcorn". Repo: el-Sc0Ville/kids_screen.)

A show picker for kids. Each kid spins (wheel, gumball machine or cards), lands on a theme,
picks 1 of 3 parent-approved shows, and the app opens it in the right streaming app.

- `index.html`: the whole web app (catalog at the top, in `SHOWS`)
- `linktest.html`: checks which links open the streaming apps on an iPad
- `manifest.webmanifest`, `icons/`: Home Screen install
- `fonts/`: Fredoka, self-hosted (SIL Open Font License, `fonts/OFL.txt`)

Hosted on GitHub Pages. No secrets in this repo: kids' names, the PIN and the TMDB key
live only in each iPad's browser storage.
